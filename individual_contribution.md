# Individual Contribution Statement

**Project Title:** Assessment-Aware Study Planner (NN + Search + CSP)

**Contribution:**

I independently designed and implemented the Assessment-Aware Study Planner project. I was responsible for all stages of development, including dataset collection, preprocessing, and feature engineering using the OULAD dataset.

I implemented and evaluated the Neural Network model and baseline models, developed the Search algorithms (UCS, Greedy, and A*), and implemented the CSP techniques (Backtracking, Forward Checking, and AC-3).

I also integrated the three components into a complete study-planning system, developed the user interface, conducted experiments, analyzed the results, and implemented the required test cases.

Finally, I prepared the project documentation, data dictionary, and demonstration materials.

**All project development and implementation tasks were completed individually.**
